# Veil Lab Bug Reports

This repository is the public, standardized bug intake for Veil Lab.

## Report a bug

Open a new issue and choose the English or 中文 bug report form. Please include reproduction steps, expected behavior, actual behavior, timestamps, screenshots, and redacted logs.

Do not post API keys, passwords, session cookies, provider secrets, full tokens, or private account credentials.

## Claude debugging

After a report is filed, maintainers can comment `@claude investigate` to trigger Claude Code GitHub Actions once the repository secret `ANTHROPIC_API_KEY` is configured.

Website bug submission on `https://veillab.org` should link or synchronize to this issue inbox.

## 中文用户

请在新建 Issue 时选择「Veil Lab 中文 Bug 报告」。提交前请移除 API Key、密码、Cookie、Token、支付信息和验证码。
